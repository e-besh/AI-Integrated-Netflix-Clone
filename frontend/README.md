# Movie - Full-Stack Streaming Platform Clone

A full-stack web application inspired by Netflix, renamed to **Movie**. This project allows users to browse movies, manage their accounts, and interact with a dynamic backend. It features a modern frontend deployed on Vercel and a robust backend connected to a serverless TiDB Cloud database, deployed on Render.

>

## Tech Stack

**Frontend:**

- React.js (or Vue.js/HTML - _adjust based on your actual frontend_)
- Vite (Build Tool)
- Deployed on **Vercel**

**Backend:**

- Node.js
- Express.js
- JWT (JSON Web Tokens) for authentication
- Deployed on **Render**

**Database:**

- **TiDB Cloud (Serverless Tier)**
- `mysql2` driver with SSL/TLS encryption
